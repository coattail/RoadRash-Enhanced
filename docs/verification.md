最新逻辑回归在 Unicorn 中执行实际编译 DLL 与原版 x86 代码，外部系统、音频、物理等回调按检查需要模拟。1.9.7 未新增 Wine 原生诊断程序测试，也未完成全场视觉试玩。

较早版本曾在开发者 M1 Mac 上确认菜单与缩放点击、倒计时完成、车手起步、U 动作及恢复骑行；用户曾确认游戏可正常运行。部分战斗、声音和动画逻辑也做过本机 Wine 原版引擎检查。

Windows 发布包从相同稳定 EXE/DLL 和素材生成，使用 Windows 自动渲染配置。**未在真实 Windows 电脑测试启动、渲染和声音。** Intel Mac 不支持；其他 Apple Silicon 系统环境尚未逐一验证。

发布前检查 ZIP CRC、核心程序哈希、相对运行路径、Mac 相对符号链接、应用本地签名，并排除个人存档、日志和旧诊断程序。这些检查不能代替实际电脑上的游玩测试。
